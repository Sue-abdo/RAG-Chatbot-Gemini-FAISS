# RAG-Chatbot-Gemini-FAISS
Retrieval-Augmented Generation (RAG) Chatbot that integrates Google Gemini AI, FAISS, and the HuggingFace UltraChat 200k dataset to deliver context-aware and knowledge-grounded responses.

## 🚀 Project Overview
This project implements a full RAG pipeline where the system retrieves relevant knowledge from a large conversational dataset and augments it with a generative AI model to produce accurate and meaningful responses.

---

## 🧠 Key Features
- Retrieval-Augmented Generation (RAG) Pipeline
- HuggingFace UltraChat 200k dataset processing
- SentenceTransformer embeddings (`all-MiniLM-L6-v2`)
- FAISS vector similarity search
- Google Gemini for intelligent response generation
- Stopwords removal using NLTK
- Terminal-based chatbot interaction

---

## 🛠 Tech Stack
- Python  
- FAISS  
- Sentence Transformers  
- HuggingFace Datasets  
- Google Gemini GenAI  
- NLTK

---

## 📌 Architecture
1️⃣ Preprocess dataset  
2️⃣ Remove stopwords  
3️⃣ Generate embeddings  
4️⃣ Build FAISS index  
5️⃣ Retrieve top relevant contexts  
6️⃣ Generate final answer using Gemini
